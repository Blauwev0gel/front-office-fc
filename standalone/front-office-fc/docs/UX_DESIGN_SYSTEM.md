# UX Design System — Module 2.2 direction

## Intent
A **mobile football game**, not a responsive SaaS dashboard. The Football Chairman screenshot supplied during design was a reference for at-a-glance club status, tiles and a dominant next-match action, not a layout to copy.

## Screen map
Home → Squad → Player Detail; Home → Staff → TD Profile / Evaluation; Home → Club; Home → League → Table / Fixtures / Results; Home → Preview → Live Match → Report → Week Summary → Home.

## Rules
- One clear primary action per phase: preview, resume, report, continue, next season.
- Four main menu areas: **SQUAD, STAFF, CLUB, LEAGUE**.
- Compact club header, form and a small number of real status metrics.
- Full-screen game views rather than stacked dashboard sections.
- Short interface labels; dialogue text only when it adds genuine decision context.
- Keep touch targets at least 44×44 CSS px, readable contrast, safe-area padding.
- Home should fit common phones when possible; long squads and tables may scroll.
- No invented finance, stadium or fan ratings to decorate empty tiles.
- Use semantic controls beneath the game styling.

## Visual direction
Retro-modern football management, clear club branding, strong hierarchy, compact scoreboards, accessible touch controls and consistent screens. Avoid long web cards and persistent SaaS-style tab bars.

## Known limitations
Previous implementation reports noted that match/report and TD-dialogue screens still carried some older interface patterns. Independent 2.2 visual review remains pending.
